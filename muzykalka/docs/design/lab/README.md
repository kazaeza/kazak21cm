# Лаборатория: стенд для O-36 (звук) и O-37 (шар)

Опубликованный стенд: https://claude.ai/artifact/6uaMcfd6hCWWpjgTWEEgPv — страница, где пользователь трогает
шар и слушает звуки до сборки приложения. Здесь её исходники и эталоны, с которых переносится код.

| файл | что это |
|---|---|
| `drop.agsl` | новый шейдер шара (O-37) — текст для `LENS_ORB_AGSL`, компилировался в Skia |
| `old-0.0.53.agsl` | шейдер из 0.0.53, для сравнения на стенде |
| `orb.js` | динамика капли (`dropMode`, `kickOf`, `drive`) и запуск AGSL в WebGL |
| `synth.js` | эталон тембров нот, тапов и комнаты (O-36) |
| `analyze.js`, `analysis.txt` | измерения эталона: пик, СКЗ, центроид, громкость, длина |
| `frames.js`, `strip-*.json` | раскадровки шара без Gradle |
| `page.template.html`, `build.py` | страница стенда и её сборка в один файл |
| `*.jpg` | раскадровки: как было (`old-pluck`), как стало (`drop-pluck`, `drop-star`) |

Команды (нужны Node и Playwright с Chromium — в облачной сессии они есть):

```bash
cd docs/design/lab
node analyze.js                         # таблица измерений звука
node frames.js strip-pluck.json out.png # раскадровка щипка
python3 build.py                        # out/muzykalka-lab.html — страница стенда одним файлом
```

AGSL запускается в браузере как есть: `orb.js` только переименовывает `main` и добавляет обёртку
(`agslToGlsl`). Кадр из Skia и кадр из WebGL на одних числах совпали — стенду можно верить по картинке,
но не по скорости: 60 к/с проверяется только на телефоне.

Правило: сначала число меняется здесь и смотрится на стенде, потом переносится в Kotlin. Не наоборот.
