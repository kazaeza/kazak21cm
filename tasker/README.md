# Таскер для чатов с клиентом

Агент читает чат с клиентом в ВК и два внутренних чата в Telegram и ведёт таскер: задачи, ТЗ с историей версий, цитаты с авторами и временем, обещания сторон, расхождения между чатами.

**Статус на 17.11.2026:** есть план и кликабельный прототип. Кода сборщиков и агента ещё нет. Следующий шаг: пилот ВК-сборщика на компьютере пользователя (см. `docs/COLLECTORS.md`).

## Что где лежит

| Путь | Что это |
|---|---|
| `docs/HANDOFF.md` | Контекст: цель, решения, что сделано, что дальше, открытые вопросы |
| `docs/ARCHITECTURE.md` | Схема работы, модель данных, правила для агента, расписание, стоимость |
| `docs/COLLECTORS.md` | Как читать ВК и Telegram, план пилота ВК |
| `config/settings.yaml` | Расписание, пороги уверенности, модели |
| `config/people.example.yaml` | Формат списка участников (без настоящих имён) |
| `schema/ops.schema.json` | Черновик контракта: что агент возвращает на каждый проход |
| `prototype/protokol.standalone.html` | Прототип интерфейса, открывается в браузере двойным кликом |
| `prototype/protokol.html` | Тот же прототип в формате Artifact (без обёртки `<html>`) |

Приватное (в `.gitignore`, в репозиторий не попадает): `private/`, `data/`, `.browser-profile/`, `config/people.local.yaml`, `.env`.

Люди, сообщения и задачи в нём выдуманы. Вкладки: Доска, Разбор, Лента чатов, Сводка, Как это работает. Время «сейчас» в прототипе зафиксировано: пт 13 ноября, 14:05.
