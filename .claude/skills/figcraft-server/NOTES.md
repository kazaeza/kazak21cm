# Что проверено (2026-11-19, FigCraft 0.18.1, облачная сессия)

Всё ниже прогнано на настоящих `figcraft-cli` и `figcraft-server` 0.18.1 из официального релиза.
Сервер был поднят локально на 127.0.0.1.

**Через сервер**
- Публикация (`collab.publish` с ключом) → вход по ссылке правки → `edit.findReplace` → `sync`.
  Новый вход видит правку, то есть она сохранилась на сервере.
- Живая синхронизация: одна сессия держит файл, вторая правит, и первая без перезахода видит новое
  значение.
- Ссылка для просмотра: правка отклоняется с «View only: the link you joined with lets you see this
  file, not change it».
- Код (`collab.share` → код): без `pref.publishServer` ищется на публичном сервере и не находится
  («No session with that code»). С адресом своего сервера вход проходит.

**Публичный сервер**
- TLS к `collab.craftapps.dev` через прокси облака: без `FIGCRAFT_CA_FILE` ошибка «isn't signed
  by an authority this app trusts», с `/root/.ccr/ca-bundle.crt` работает.
- `collab.serverInfo`: `maxFileMb: 8`, `idleDays: 30`, `open: true`. Файлы на публичный сервер в
  тестах не выкладывались.

**Размеры** (таблица в `SKILL.md`, «Размер файла»)
- 219, 705 и 961 МиБ. Снимок на сервере примерно в 1,33 раза больше файла (base64).
- 961 МиБ через сервер не проходит ни при каком `max_file_mb`.

**Инструменты**
- `shrink_figcraft.py`: 961 → 219 МиБ (шумовые RGBA-картинки), 187 → 1,6 МиБ (фотоподобные). Рендер
  до и после совпадает по раскладке, прозрачность сохранена, `figcraft-cli info` открывает
  результат.
- `get_figcraft.sh`: скачивание, сверка SHA-256, подменённый архив удаляется с кодом 1.
- `figcraft_live.py`: на настоящем CLI и на заглушке (ошибки входа, ошибки команд, маскировка
  секретов, падение CLI).

**Файлы и CLI**
- `info`, `render`, `export` (PNG по кадрам), `convert` в `.pdf` и `.svg`, `run --out`.
- 0.18.1 открывает файл, сохранённый веб-версией 0.15.
- Цветные эмодзи: нативный CLI сам берёт системный Noto Color Emoji. Обрезка начинается выше ~110 px
  итогового размера: 160 px × 0,5 цел, 260 px × 0,5 обрезан.
- `image.replace` оставляет старые картинки в архиве даже после пересохранения и `convert`.

**Веб-версия** (0.15.0, история со сторис, `references/web-build.md`)
- Локальный хостинг zip-сборки, headless Chromium (`swiftshader`, `?webgl`).
- Цветные эмодзи через Local Font Access и разрешение `local-fonts`. Обрезка крупных эмодзи.
- Save и «Export page as PNG» отдают файлы браузерной загрузкой. С кириллическим именем документа
  файл называется `download`.

**Не проверено**
- Работа через настоящий интернет со своим сервером на VPS (TLS от Let's Encrypt, Caddy).
  Известны только локальные времена.
- Вход по ссылке, выданной десктопным приложением (а не `figcraft-cli`).
- Хранилища (Dropbox, Яндекс Диск) для передачи файла: нужен ключ пользователя.
