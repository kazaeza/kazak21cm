# S-01 · Аналитика практики и адаптивный слуховой блок

«Прогресс → Экспорт статистики» сохраняет JSON формата `muzykalka-practice`, версия 1. Снимок читается одной транзакцией. Обычный бэкап в настройках нужен для восстановления библиотеки.

- `attempts` — исходные ответы. У строки есть id, sessionId (может отсутствовать), режим, уровень, ключ задания, ожидаемый и данный ответ, правильность, задержка в мс, тональность, время Unix в мс и центы там, где они измеряются. В «Пропевке» сохраняется первая попытка. В старых данных пауза могла сдвинуть время события назад. Нулевое hintLevel в упражнениях не подтверждает отсутствие повторного прослушивания.
- `sessions` — начало, конец, тип и учебный день. Пустое окончание означает незавершённую сессию. ADAPTIVE_DUEL, ADAPTIVE_PROBE и ADAPTIVE_CONTEXT описывают назначение всего сета. Пользователь может пропустить часть. Даты, причину пропуска и успешность назначения нельзя выводить из одного идентификатора. Фактические ответы привязываются по sessionId. Старые SET не содержат подробностей плана.
- `orders` — отдельное исполнение песни или риффа, подсказка, самооценка, тональность и результат FSRS. formulaAccuracy = -1 означает, что вопрос не задавался. `exams` — результаты по навыкам, связанные с сессиями.
- `appVersion`, `exportZone` и `dayStartHourAtExport` — значения на момент выгрузки. Исторические настройки устройства неизвестны. Выгрузки полные и перекрываются. Для одного непрерывного экземпляра базы анализировать последний снимок. Времена ответов разных задач и самооценок несопоставимы.

## Пилот S-01

Обычный полный сет может отдать один 90-секундный блок из четырёх минут Тира на пару, проверку или гармонический контекст. Окно — 14 учебных дней. Для дуэли нужны ошибки в одной паре на одном уровне в разные дни. В отдельный день после дуэли программа проверяет обычные ответы на обе ступени. При достаточном числе попаданий предлагает «Над аккордами». Второе основание предложить этот режим — отставание минимум на 20 п.п. на сходном материале по меньшей мере в трёх сочетаниях ступени и лада. Пороги пробные. Время ответа, прогноз FSRS и самооценка песни не используются как диагноз слуха.

Для оценки пилота сравнивать первые ответы обычного Тира по дням, уровню, ступени и ладу с числителем и знаменателем. Отдельно смотреть «Над аккордами», контроль переноса и исполнение песен. Сет отмечен как адаптивный даже при досрочном выходе. Задания внутри обычного Тира могут выбираться с учётом истории. Для независимого контрольного результата использовать отдельный «Замер уровня».
