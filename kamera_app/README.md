# ferment — Трекер посола, ферментации и вяления (Android APK v0.4)

Офлайн Android-приложение (`com.kamera.curing`, minSdk 24 / targetSdk 35) для учёта посола (`3°C`), ферментационной камеры (`12°C`), вакуумного выравнивания корки (`3°C`), холодного копчения и ферментации острых перцев.

## Что нового в v0.4.0
- Переименовано в **ferment**, а 12°C-камера — в **Ферм-камеру 12°C**.
- Вкладки этапов внутри карточки (`Посол | Ферм. 12° | Вакуум | Готово`) работают как безопасный просмотр — тап по вкладке больше не переносит кусок автоматически; перенос выполняется только отдельной кнопкой действия.
- Исправлен свайп «Назад» на Android 13–15 (`enableOnBackInvokedCallback="true"` + динамическая регистрация `OnBackInvokedCallback` и единый `onBackPressed()`), чтобы возвращать на главный экран вместо выхода из приложения.
- Готовые куски убираются в **Архив** с дегустационным вердиктом.

## Пересборка APK
```bash
cd kamera_app
./build_apk.sh
```
