# nightcap. 3.0 — Космическая туманность коктейлей

Офлайн-приложение для вечернего вайб-коктейлинга на Android в эстетике **Celestial Speakeasy**: открыл, поймал настроение в объёмной 3D-туманности тегов, нажал **«Заебенить»** — и сразу смешал коктейль дома.

## Что нового в версии 3.0 (Design System Overhaul)

- **Эстетика Celestial Speakeasy**: палитра глубокого обсидиана (`#07070c`), дымчатого стекла и тёплого шампанского золота (`#e8c78e`) — яркий цвет остаётся только у живой туманности и самих коктейлей.
- **Редакционная типографика (встроена офлайн)**: люксовая антиква **Cormorant Garamond** для заголовков и названий коктейлей в паре с геометрическим гротеском **Manrope** (`tabular-nums` для градусов и граммовок).
- **Живая физика Vaul + Motion + Sonner (`120Hz`)**:
  - Шторка подборки и экран рецепта с настоящей инерцией свайпа вниз, резиновым сопротивлением вверх и **глубинным масштабированием заднего фона** (`scale(0.955)` + скругление углов).
  - Плавно перетекающая капсула в нижнем доке навигации, в фильтрах настроения, в Барной карте и в переключателе порций `×1 / ×2 / ×4`.
  - Направленное перетекание экранов при переключении вкладок, тактильное сжатие при нажатии и плавающие тосты со свайпом вверх.
- **Космос 2.0 + Взрыв «Заебенить» + Crystal Glass 2.0**: объёмная JWST-туманность с пылевыми рукавами и созвездием вокруг выбранного тега, плазменная дуга и двойная ударная волна с многоимпульсной вибрацией при нажатии «Заебенить», хрустальная векторная отрисовка всех 10 типов бокалов с каустикой и гранёным льдом.
- **200 проверенных рецептов & 36 вайб-тегов**: вся личная коллекция, классика IBA, Sloe Gin, конфитюры, шоты, кувшины и `0,0%` — **100% офлайн**.

## Готовый Android `.apk`

Собранный и подписанный APK лежит в [`releases/nightcap-v3.0.0.apk`](releases/nightcap-v3.0.0.apk).
Ставится прямо поверх прошлой версии с сохранением Полки и Тайника:
1. Скачай `nightcap-v3.0.0.apk` на телефон.
2. Открой файл и подтверди установку / обновление.

## Локальная сборка и тесты

```bash
# Юнит-тесты базы рецептов, поиска, полки и визуализации
bun test

# Сборка офлайн веб-бандла (dist/)
bun run build:web

# Полная сборка подписанного Android APK (releases/nightcap-v3.0.0.apk)
./scripts/build-apk.sh
```
