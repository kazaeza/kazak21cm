# kazak21cm

В репозитории два независимых проекта:

- `roman_merzlikin_bday/` — поздравительная гифка. С остальным не связана.
- `tasker/` — таскер, который собирает задачи из чата с клиентом в ВК и из двух внутренних чатов в Telegram. Это основной активный проект.

## Работа над таскером

1. Сначала прочитай `tasker/docs/HANDOFF.md`: цель, решения пользователя, что уже сделано, что дальше.
2. Потом `tasker/docs/ARCHITECTURE.md`, `tasker/docs/COLLECTORS.md`, `tasker/config/settings.yaml`.
3. Пользователь пишет по-русски, отвечай по-русски, коротко и по делу.

## Правила для данных

Репозиторий публичный. Никогда не коммить и не пуш:

- переписку клиента и выгрузки чатов (папка `tasker/data/`);
- профиль браузера и сессии ВК (`tasker/.browser-profile/`);
- токены, ключи API, `.env`;
- настоящие имена и роли участников чатов (`tasker/config/people.local.yaml`, папка `tasker/private/`).

Эти пути уже в `tasker/.gitignore`. Перед каждым коммитом проверяй `git status` и `git diff --cached --stat`.

Если приватных файлов нет на диске, их содержимое лежит в промпте, которым пользователь запустил сессию. Если и там нет, спроси пользователя.
