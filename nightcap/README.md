# nightcap. 4.0 — Неоновый Космос

Офлайн-приложение для вечернего вайб-коктейлинга на Android: открыл, поймал вайб в невесомом 3D-облаке звёзд, нажал **«Заебенить»** — и выбрал коктейль на космическом свайп-подиуме.

## Что нового в версии 4.0

- **Бескаркасное звёздное облако + физика «дорогих часов»**: убрали громоздкие «кирпичи-пилюли» — теперь в космосе парят живые звёзды-надписи на цветном свечении. При кручении ближайшая к центру звезда мягко подтягивается магнитом в фокус с микро-щелчком, раскрывает подзаголовок, а соседние звёзды уступают ей место.
- **Шёлковое растворение облака по кнопке «Заебенить»**: вместо тяжеловесного конфетти звёзды плавно разлетаются за края экрана, туманность на фоне переливается в цвет подобранного коктейля, и на `120Hz` раскрывается витрина выбора.
- **Космический Подиум + Свайп-лента**: вместо простыни из 15–20 одинаковых строк — крупный свайп-подиум лучших хитов с большим бокалом, вкусовым описанием, превью ингредиентов и плавной сменой цвета туманности при перелистывании (с переключением на полный список в один тап).
- **Единый космический неон-стиль (`120Hz` Zero-Blur)**: футуристичная кириллическая пара **Unbounded + Manrope** (встроены офлайн), физика шторок **Vaul**, плавно перетекающие капсулы навигации, сбалансированный док без перегрузки.
- **200 проверенных рецептов & 36 вайб-тегов**: вся личная коллекция, классика IBA, Sloe Gin, конфитюры, шоты, кувшины и `0,0%` — **100% офлайн**.
