# nightcap. 5.0 — Неоновый Космос

Офлайн-приложение для вечернего вайб-коктейлинга на Android: открыл, навёл звезду в центр невесомой 3D-туманности, нажал **«Заебенить»** — пронёсся секундный космический шейкер-ритуал, и перед тобой полноценная страница выбора коктейлей.

## Что нового в версии 5.0

- **Чистое звёздное свечение без рамок**: убрали все линейные обводки и овальные кольца — активная звезда парит в мягком неоновом гало с искрами.
- **Мгновенная готовность «Заебенить» без второго тапа**: как только звезда попадает в магнитный фокус, кнопка **«Заебенить»** уже заряжена (без лишних цифр-«кредитов»). Для поиска по слову рядом аккуратная кнопка `🔍`.
- **1-секундный ритуал с космическим шейкером**: по нажатию «Заебенить» звёзды растворяются, облака закручиваются в воронку, космический шейкер трясётся со льдом в такт трём тактильным щелчкам (`Ловим вайб…` → `Взбиваем со льдом…` → `Подаём!`) и мягко открывает выдачу.
- **Отдельная полноэкранная страница результатов с чёткой иерархией**: вместо тесной шторки — полноценный экран, где с первого взгляда видны и главный `#1 Выбор момента`, и 2-колоночная сетка остальных вариантов ниже + кнопка перемешивания `↻`.
- **Минималистичный 3-табовый док (`Космос · Карта · Тайник`)**: убрали дублирующую кнопку «Микс» и лишнюю «Полку» — навигация стала невесомой и незаметной.
- **Новая категория `🍇 Крем де касис` — 207 рецептов и 37 вайб-тегов**: добавили авторскую подборку с чёрносмородиновым ликёром (`Кир`, `Касис Шприц`, `Касис Бурбон Сауэр`, `Бургундский Негрони`, `Арно`, `Касис Джин Физз`, `Касис Маргарита` + `Кир Рояль` и `Эль Диабло`), **100% офлайн**, `120Hz` Zero-Blur.

## Готовый Android `.apk`

Собранный и подписанный APK лежит в [`releases/nightcap-v5.0.0.apk`](releases/nightcap-v5.0.0.apk).
Ставится прямо поверх прошлой версии с сохранением Тайника:
1. Скачай `nightcap-v5.0.0.apk` на телефон.
2. Открой файл и подтверди установку / обновление.
