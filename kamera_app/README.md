# КАМЕРА — Трекер вяления, холодного копчения и ферментации (Android APK v0.3)

Лёгкое офлайн Android-приложение (`com.kamera.curing`, minSdk 24 / targetSdk 35) для учёта посола, вяления, вакуумного выравнивания корки, холодного копчения и ферментации острых перцев.

## Архитектура v0.3
- **3 вкладки внизу:** `Погреб` (активные партии и ориентировочное время до цели), `＋` (компактная 1-экранная закладка с поддержкой «Уже лежит»), `Архив` (дегустации с вердиктами и планы на будущее).
- **4 состояния мяса:** `Посол` $\rightarrow$ `Вяление` (оболочка / без оболочки / мембрана + флаг копчения) $\rightleftarrows$ `Вакуум` (выравнивание корки) $\rightarrow$ `Готово` (дегустация).
- **Фиксация веса в вакууме:** на этапах `Посол` и `Вакуум` весы скрыты — показывается только таймер дней и кнопка следующего шага. Арочный дайл взвешивания активен только на этапе `Вяление`.
- **Нативная оболочка:** `MainActivity.java` с обработкой `WindowInsets.Type.ime()` (клавиатура не перекрывает поля на Android 11–15+), кнопкой скрытия клавиатуры, динамическим статус-баром, локальным хранением JSON и Share-бэкапом.

## Пересборка APK
```bash
cd kamera_app
./build_apk.sh
```
