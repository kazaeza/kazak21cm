# Музыкалка

Android-приложение, которое закрывает ровно две дыры: **имена для звуков** (ступени) и **тренировку
вспоминания** (интервальные повторения своей музыки в случайной тональности). Главная цифра —
«Играю с ходу: N».

- План и диагноз — документ «Музыкалка — приложение для слуха и памяти».
- Архитектура — [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
- Тикеты и порядок работ — [`docs/ROADMAP.md`](docs/ROADMAP.md).
- Решения — [`docs/DECISIONS.md`](docs/DECISIONS.md).

## Установить на телефон

1. На Pixel открыть страницу релиза `muzykalka-latest` этого репозитория (вкладка Releases на GitHub).
2. Скачать `muzykalka-<версия>.apk` → открыть → разрешить установку из этого источника.
3. Новые версии ставятся поверх: ключ подписи один, данные сохраняются.

## Собрать самому

```bash
muzykalka/scripts/setup-android-sdk.sh        # один раз: Android SDK в ~/android-sdk
cd muzykalka
./gradlew check                                # тесты ядра, smoke-тест запуска, lint
./gradlew assembleRelease                      # app/build/outputs/apk/release/app-release.apk
```
