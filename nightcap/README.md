# nightcap. — Космическая туманность коктейлей

Офлайн-приложение для вечернего вайб-коктейлинга на Android: открыл, поймал настроение в 3D-туманности тегов — и сразу смешал коктейль дома.

## Что внутри

- **Космос (3D-туманность тегов)**: вращающаяся сфера из **30 авторских вайб-тегов с эмодзи**, 8 фильтров настроения, 120Hz-оптимизированная туманность, кнопка «Удиви меня», живой поиск с подсказками и подтверждение выбора кнопкой **«Заебенить»**.
- **126 проверенных рецептов**: классика IBA, современные хиты, линейка со **Sloe Gin** и **конфитюрами/джемами**, шоты, кувшины, винные/пивные миксы, тёплые согревающие и коллекция `0,0%` — каждый из 30 тегов покрыт минимум 5 коктейлями.
- **Визуализация коктейля в бокале**: процедурная векторная отрисовка на каждой карточке и на экране рецепта — 10 форм бокалов (купе, мартини, рокс, хайбол, винный, шот, флют, тики, кружка, кувшин), цвет и слои, пенка, лёд (куб, кубики, колотый), живые пузырьки, кромки (соль, сахар, чили, какао) и 18 гарнишей.
- **Пошаговый экран рецепта**: ингредиенты с пересчётом порций (`×1 / ×2 / ×4`), метод, бокал, лёд, гарниш, блок «Чем заменить и лайфхаки» и похожие по вайбу коктейли.
- **Полка**: максимально простой выбор основных бутылок твоего домашнего бара (22 базовые позиции, включая Sloe Gin, + 3 быстрых пресета) и мгновенный фильтр «Только с полки» в Космосе и Барной карте.
- **Барная карта**: поиск и фильтрация по всей коллекции.
- **Тайник**: избранные коктейли (хранятся локально на устройстве).
- **100% офлайн**: работает без интернета, с edge-to-edge оформлением, тактильной отдачей (вибрацией) и нативной обработкой кнопки «Назад».

## Готовый Android `.apk`

Собранный и подписанный APK лежит в [`releases/nightcap-v1.2.0.apk`](releases/nightcap-v1.2.0.apk).
Чтобы установить на Android:
1. Скачай `nightcap-v1.2.0.apk` на телефон.
2. Открой файл и при запросе разреши установку из этого источника (Telegram / Файлы / Chrome).

## Локальная сборка и тесты

Требования: [Bun](https://bun.sh), Java 11+, Android SDK (`ANDROID_HOME`, platform `android-35`, `build-tools/35.0.0`), Python 3 + Pillow (для генерации иконок).

```bash
# Юнит-тесты базы рецептов, поиска, полки и визуализации
bun test

# Сборка офлайн веб-бандла (dist/)
bun run build:web

# Полная сборка подписанного Android APK (releases/nightcap-v1.2.0.apk)
./scripts/build-apk.sh
```
