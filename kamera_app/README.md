# ferment — Трекер посола, ферментации и вяления (Android APK v0.5)

Офлайн Android-приложение (`com.kamera.curing`, minSdk 24 / targetSdk 35) для учёта посола (`3°C`), ферментационной камеры (`12°C`), вакуумного выравнивания корки (`3°C`), холодного копчения и ферментации острых перцев.

## Что нового в v0.5.0
- **Никаких вкладок внутри куска — наглядная Хронология:** открыв кусок, сразу видишь сводку дней (`Посол: 14 дн · Ферм. 12°: 28 дн · Вакуум: 7 дн`) и вертикальную цепочку всех его этапов с датами.
- **Полное редактирование постфактум:** тап по любой строчке Хронологии позволяет задним числом поменять дату старта/окончания, формат (оболочка / без оболочки / мембрана / копчение) или удалить ошибочный этап; кнопка `＋ Следующий этап` даёт записать перенос за любую прошлую дату.
- **Редактируемый журнал взвешиваний:** каждый замер тапается для правки граммов и даты, плюс прямо на дайле взвешивания и кнопкой `＋ Замер за дату` можно вносить веса за прошлые дни.
- **Новая фирменная иконка (Legacy + Adaptive Android 8–15):** графитовый фон `#18191C`, кремовая курсивная литера `f` с засечками и терракотово-золотая капля ферментации.
