# nightcap. 2.0 — Космическая туманность коктейлей

Офлайн-приложение для вечернего вайб-коктейлинга на Android: открыл, поймал настроение в объёмной 3D-туманности тегов, нажал **«Заебенить»** — и сразу смешал коктейль дома.

## Что внутри (Версия 2.0)

- **Космос 2.0 (Объёмная 3D-туманность)**: анизотропные газовые облака, тёмные пылевые рукава в духе Hubble/JWST, параллакс-звёзды с дифракционными лучами, кометы, реактивное ядро и орбитальное кольцо-созвездие вокруг выбранного тега — при сохранении идеальных **120Hz** без просадок кадров.
- **Фирменный взрыв «Заебенить»**: плазменная дуга от выбранного вайба к кнопке, двойная хроматическая ударная волна, гиперпрыжок искр, разлетающиеся эмодзи и многоимпульсный виброотклик.
- **Crystal & Liquid 2.0 (Хрустальная визуализация бокалов)**: процедурная векторная отрисовка всех 10 форм бокалов с цветной каустикой на барной стойке, преломлением в толстом дне, объёмным цилиндрическим светом жидкости, 3D-менисками слоёв, гранёным льдом, каплями конденсата, бархатной пенкой и детализированными гарнишами.
- **200 проверенных рецептов & 36 вайб-тегов**: вся личная коллекция из записной книжки (Ягер, Фернет, Абсент, Адвокат, Лимончелло, советская классика, 6 авторских джин-тоников), классика IBA, линейка со **Sloe Gin** и **конфитюрами**, шоты, кувшины и `0,0%` — строго 5–11 выверенных коктейлей на каждом теге без повторов.
- **Пошаговый экран рецепта**: ингредиенты с пересчётом порций (`×1 / ×2 / ×4`), метод, бокал, лёд, гарниш, блок «Чем заменить и лайфхаки» и похожие по вайбу коктейли.
- **Полка, Барная карта и Тайник**: 24 базовые бутылки домашнего бара с фильтром «Только с полки», мгновенный поиск и локальное избранное — **100% офлайн**.

## Готовый Android `.apk`

Собранный и подписанный APK лежит в [`releases/nightcap-v2.0.0.apk`](releases/nightcap-v2.0.0.apk).
Чтобы установить на Android (в том числе поверх прошлой версии с сохранением Тайника и Полки):
1. Скачай `nightcap-v2.0.0.apk` на телефон.
2. Открой файл и подтверди установку / обновление.

## Локальная сборка и тесты

Требования: [Bun](https://bun.sh), Java 11+, Android SDK (`ANDROID_HOME`, platform `android-35`, `build-tools/35.0.0`), Python 3 + Pillow (для генерации иконок).

```bash
# Юнит-тесты базы рецептов, поиска, полки и визуализации
bun test

# Сборка офлайн веб-бандла (dist/)
bun run build:web

# Полная сборка подписанного Android APK (releases/nightcap-v2.0.0.apk)
./scripts/build-apk.sh
```
