# Большой файл (около 1 ГБ) в облачной сессии

Через сервер живьём проходят только файлы примерно до 700 МиБ: см. «Размер файла» в `SKILL.md`. Для
файла больше остаются два пути:

1. **Ужать и работать живьём.** Файл один раз попадает в облако, ты его ужимаешь
   (`shrink_figcraft.py`) и отдаёшь человеку. Человек публикует ужатый файл на свой сервер, и
   дальше работа идёт по разделу A.
2. **Работать с файлом напрямую, без сервера.** Скачать файл в облако, открыть headless, править,
   сохранить и вернуть человеку. Это не живая работа: человек увидит результат, когда заберёт
   файл.

## Как файл попадает в облако и обратно

Облачная сессия скачивает и отдаёт файлы по HTTPS. Чат и MCP-коннекторы (Google Drive и т.п.) для
гигабайта не годятся: содержимое шло бы через контекст.

- **Хранилище с API.** Подойдёт Dropbox, Яндекс Диск или S3-совместимое. Ключ попроси через
  `request_credential`, прокси сам подставит его в запросы. Никогда не проси вставить ключ в чат.
- **Публичная ссылка на скачивание.** Это проще, но любой, у кого есть ссылка, скачает файл.
  Годится только для неконфиденциального и ненадолго.
- **Выгрузка обратно.** Новый файл под новым именем, исходник не перезаписывать.

## Работа с файлом напрямую (замеры, FigCraft 0.18.1)

- Открыть файл на 961 МиБ, поправить текст и сохранить заняло 7,5 с и 3,5 ГБ памяти на пике.
  Попытка публикации того же файла доходила до 5,8 ГБ. В облачном контейнере 16 ГБ, этого
  хватает.
- Пакет правок на одном процессе `figcraft_live.py`: `open_file`, команды, `save_file` с новым
  путём. Шаги `join` и `sync` не нужны.
- `render` и `export` с `--node`: показывай человеку картинки кадров, а не гоняй гигабайт ради
  просмотра.

```json
[
  {"tool": "open_file", "args": {"path": "/abs/work/menu.figcraft"}, "timeout": 900},
  {"tool": "inspect_document", "args": {"depth": 2, "outline": true}},
  {"command": "edit.findReplace", "params": {"find": "Капучино 250", "replace": "Капучино 270"}},
  {"tool": "save_file", "args": {"path": "/abs/work/menu-edited.figcraft"}, "timeout": 900}
]
```

## Что узнать у человека заранее

- Из чего состоит гигабайт: `.figcraft` — это zip, у которого папка `images/` и `document.json`.
  Если почти всё картинки, ужатие решит вопрос.
- Для чего макет: экран (картинки до 2048 px) или печать (около 3600 px для A4 при 300 dpi).
- Нужна ли живая совместная работа или хватит «прислал файл — получил файл».
